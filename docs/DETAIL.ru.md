# Rust Fullstack Elite

`@alsergeevich/dsh-rust-fullstack` превращает DeepSeek Harness в специалиста по Rust full-stack, как только в сессии обнаруживается работа с Rust.

## Зачем устанавливать

- Элитный навык `rust-fullstack-elite` подключается автоматически — не нужно вызывать `/skill` и повторно объяснять контекст.
- Плагин знает проект: Cargo root, edition, MSRV, toolchain, фреймворки, базы данных, версии зависимостей, миграции.
- Принцип «сначала документация»: версионно-зависимые утверждения проверяются по официальным источникам через ограниченный инструмент `rust_docs`.
- Данные остаются актуальными: `rust_skill_check` обновляет версионный baseline, `rust_skill_update` устанавливает проверенный пакет навыка из GitHub.
- Ваши правки сохраняются: глобальный навык можно редактировать, изменения защищены хешами манифеста, перед принудительным обновлением создаётся резервная копия.

## Установка

Из локального каталога:

```text
plugin_manager install_bundle target=F:\path\to\dsh-rust-fullstack
```

Из GitHub (воспроизводимо):

```text
https://github.com/alsergeevich/dsh-rust-fullstack.git#<полный-40-символьный-commit>
```

Плагин Host-only, без шага сборки и без импортов runtime-пакетов DSH. После установки попросите endpoint на Axum + SQLx — должно появиться вступление об активации.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `rust_skill_status` | Состояние навыка, глобальной копии, актуальности и проекта |
| `rust_skill_check` | Обновление официальных версий и проверка доступности документации |
| `rust_skill_update` | Проверка и установка пакета навыка из GitHub (требует подтверждения) |
| `rust_docs` | Загрузка страницы официальной документации из allowlist |
| `rust_project_scan` | Сканирование Cargo-проекта |

## Безопасность

Загружаются только разрешённые официальные хосты. Пакеты навыка проходят проверку индекса, SHA-256 и лимитов размера, записываются атомарно. Удалённый код не исполняется. Плагин не заменяет собственный JavaScript — обновляйте пакет через `plugin_manager`.
